# Plan: Print Report with Excel-Like Style

## Goal
Add a "Print Report" button to the admin reports page that triggers `window.print()` with custom `@media print` CSS, producing an Excel-style printed report that includes the best-selling products horizontal bar chart.

---

## Files to Modify

| File | Change |
|------|--------|
| `C:\wamp64\www\sweetheaven\admin\reports.php` | Add print button, print-only header, `@media print` CSS, JavaScript print functions |
| `C:\wamp64\www\sweetheaven\api\reports.php` | Add `print=1` parameter to return all orders (bypass pagination) |

---

## Step 1: API Change — `api/reports.php`

Add a `print` GET parameter. When `print=1`, skip `LIMIT/OFFSET` on the orders query so all orders are returned.

- Add `$printMode = isset($_GET['print']) && $_GET['print'] === '1';` near line 11
- Wrap the `LIMIT/OFFSET` clause in the orders query (lines ~130-143) with `if (!$printMode)`
- Set `$totalPages = $printMode ? 1 : max(1, ceil($totalOrders / $perPage));`

No breaking changes — existing AJAX calls work as before.

## Step 3: JavaScript Changes — `admin/reports.php` `<script>` block

### New functions:
- `getPeriodLabel()` — returns human-readable period name
- `getDateRangeText()` — returns formatted date range string
- `printReport()` — main print workflow:
  1. Populate the print-only header with period/date info
  2. Fetch ALL orders via `?print=1`
  3. Render all orders into `#ordersTableAll`
  4. Call `window.print()` after a short delay
- `renderAllOrdersForPrint(orders)` — renders all orders into the hidden tbody

---

## Step 4: Print CSS — `@media print` block in `admin/reports.php`

### Hide on print:
- Sidebar, filter bar, pagination, export/print buttons, notification bell
- Decorative icons in summary cards
- Avatar circles in orders table

### Show on print:
- Print-only report header (`#printReportHeader`)
- All tables with Excel-like styling

### Excel-like table styling:
- Blue header rows (`#2563eb` background, white text)
- Solid borders on all cells (`1px solid #999`)
- Clean, compact layout (11px font)
- Status badges flattened to bordered labels

### Charts:
- ApexCharts SVGs print natively (vector) — no conversion needed
- `max-width: 100%; height: auto` on SVG elements

### Page breaks:
- `break-inside: avoid` on table sections and chart containers
- `page-break-inside: avoid` for older browser support

---

## Edge Cases

| Case | Handling |
|------|----------|
| No data loaded | Print with whatever is on screen + period header |
| API fetch fails | Fallback: `window.print()` with current state |
| Very large order count | Add `LIMIT 500` in print mode if needed |
| Tailwind CDN print utilities | Use dedicated `@media print` CSS instead |
| Charts not rendered yet | Shows "Loading..." — acceptable |
