## Step 4: Create Reports API (`api/reports.php`)

### Endpoint: `GET /sweetheaven/api/reports.php`

**Parameters:**
- `period` — `daily`, `weekly`, `monthly`, `yearly`, `custom`
- `start_date` — YYYY-MM-DD (for custom period)
- `end_date` — YYYY-MM-DD (for custom period)
- `category_id` — integer (optional, filter by product category)
- `page` — integer (for pagination, default 1)

**Response (JSON):**
```json
{
  "total_orders": 150,
  "total_sales": 2500000,
  "total_products_sold": 420,
  "total_revenue": 2500000,
  "best_selling": [{"name": "...", "quantity": 50, "revenue": 500000}],
  "status_summary": {"pending": 10, "processing": 5, "shipped": 20, "delivered": 100, "cancelled": 15},
  "orders": [{"id": 1, "customer": "...", "amount": 25000, "status": "delivered", "date": "2026-01-15"}],
  "total_pages": 15
}
```

**SQL Logic:**
- Period filters use `WHERE order_date BETWEEN ? AND ?`
- Daily: today only
- Weekly: current week (Monday-Sunday)
- Monthly: current month
- Yearly: current year
- Custom: user-specified date range
- Category filter: `JOIN order_items oi ON o.id = oi.order_id JOIN products p ON oi.product_id = p.id WHERE p.category_id = ?`
- Best-selling: `GROUP BY p.id ORDER BY SUM(oi.quantity) DESC LIMIT 10`
- Status summary: `GROUP BY status`
